## Selected engineering work

### [Concord](https://github.com/DenGian/concord)

_Real-time systems · Authorization · Application architecture_

A full-stack community platform with role-aware messaging. It pairs PostgreSQL modelling and server-side authorization with SSE delivery; its single-instance scaling limit is documented in the repository.

### [Image Converter](https://github.com/DenGian/image-converter)

_WebAssembly · Browser systems · Product engineering_

A browser-based batch converter that keeps files on the user's device. WebAssembly and Web Workers handle conversion, while resource limits, accessibility checks and browser tests address practical constraints.

### [Smart Light Controller](https://github.com/DenGian/smart-light-controller)

_Reliability · Failure recovery · Automated testing_

A .NET smart-light simulation with deterministic scheduling, including overnight windows. Replaceable time and output boundaries make fault thresholds, safe-mode recovery and layered tests straightforward to exercise.

### [Roomba Webots Digital Twin](https://github.com/DenGian/roomba-webots-digital-twin)

_Robotics · Autonomous navigation · Simulation_

A Webots/Python robotic-vacuum simulation using a state machine for LiDAR-assisted navigation, carpet-aware cleaning and battery-aware docking.
